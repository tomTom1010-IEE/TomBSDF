tom/RectAreaLight

Emitter

ParameterType / range / defaultMeaning
AreaLightEnabledFloat
Range: 0, 1
Default: 1		Enable this emitter. Studio hiding its control renderer also disables its contribution.
AreaLightColorColor
Default: Shader default		Emitter color, decoded using AreaLightColorInput before entering the linear scene protocol.
AreaLightRadianceFloat
Range: 0, 100
Default: 1		Linear radiance multiplier, not lumens or Unity point-light intensity. Larger area at fixed radiance emits more total light. Distance falloff is already integrated.

Shape

ParameterType / range / defaultMeaning
AreaLightWidthFloat
Range: 0.001, 10
Default: 1		Emitter width before object transform scaling. Local +Z is the emitting front.
AreaLightHeightFloat
Range: 0.001, 10
Default: 1		Emitter height before object transform scaling. Rotate the Studio item to aim its local +Z at the subject.
AreaLightTwoSidedFloat
Range: 0, 1
Default: 0		Allow emission from both sides of the plane. This does not enable shadows or make the carrier visible.

Selection

ParameterType / range / defaultMeaning
AreaLightPriorityFloat
Range: -10, 10
Default: 0		Higher priority is selected first. The prototype supports at most four emitters per camera; overflow is ignored.

Input Contract

ParameterType / range / defaultMeaning
AreaLightColorInputFloat
Range: 0, 1
Default: 0		0: ME sRGB color values, decoded once. 1: values already describe linear radiance. Does not change the game's color space.

tom/BSDF

Textures

ParameterType / range / defaultMeaning
GlintMaskTexture
Default: Shader default		Linear red channel multiplies GlintWeight. White or no map preserves the scalar; black restores smooth direct specular. Independent ST affects only the mask, not the stable UV microstructure. Does not clip coverage.
MainTexTexture
Default: Shader default		RGB base color; white multiplies BaseColor unchanged. Alpha is used only by BSDFCutout.
NormalMapTexture
Default: Shader default		Normal data. Encoding is explicit; use UnityPacked for Unity-imported normals, RGB for blue normals, AG for exported alpha/green normals.
MetallicMapTexture
Default: Shader default		Red channel multiplies Metallic. White or no map keeps the scalar.
RoughnessMapTexture
Default: Shader default		Red channel multiplies perceptual Roughness. White or no map keeps the scalar; black is smooth.
OcclusionMapTexture
Default: Shader default		Red channel multiplies Occlusion. Affects indirect diffuse and optionally probe specular through SpecularOcclusionStrength; never direct lights or emission.
ORMMapTexture
Default: Shader default		Optional packed data: R=occlusion, G=roughness, B=metallic. Enabled by UseORM; multiplies the corresponding scalar values.
EmissionMaskTexture
Default: Shader default		RGB emission multiplied by EmissionColor and EmissionIntensity. Black or no texture produces no emission.
AnisotropyMapTexture
Default: Shader default		Linear red-channel data multiplies Anisotropy. White or no texture retains the slider; black is isotropic. Independent ST; shares RoughnessMap filtering/wrap sampler.
AnisotropyRotationMapTexture
Default: Shader default		Linear red-channel angle adds 0..360 degrees to AnisotropyRotation in the mesh UV tangent frame. Black or no texture adds zero. Independent ST; shares RoughnessMap sampler. Avoid filtered discontinuities between 0 and 1; opposite directions describe the same unoriented lobe.
NormalMapDetailTexture
Default: Shader default		Independent detail normal, reoriented onto the base normal using RNM. Its UV scale and offset are independent of MainTex and NormalMap.

Base Material

ParameterType / range / defaultMeaning
BaseColorColor
Default: Shader default		Base reflectance color. For dielectrics this is diffuse color; for metals it is normal-incidence specular reflectance.
MetallicFloat
Range: 0, 1
Default: 0		0 is dielectric, 1 is conductor. Fractional values mix the two; metals have no diffuse lobe.
RoughnessFloat
Range: 0, 1
Default: 0.5		GGX perceptual roughness; microfacet alpha=r*r with only a numerical alpha floor of 0.001.
DiffuseRoughnessFloat
Range: 0, 1
Default: 0		EON diffuse roughness; 0 is Lambert. Does not change the GGX specular roughness.
IORFloat
Range: 1, 3
Default: 1.5		Dielectric interface IOR relative to air. F0=((IOR-1)/(IOR+1))^2; IOR=1 disables dielectric interface reflection.
SpecularWeightFloat
Range: 0, 1
Default: 1		Weights the dielectric reflection lobe, including grazing reflection. Metals are unaffected. 1 is the physical interface reference.
SpecularColorColor
Default: Shader default		Tint of dielectric normal-incidence reflection. White is the physically neutral dielectric reference.
UseORMFloat
Range: 0, 1
Default: 0		0 uses separate metallic/roughness/AO maps; 1 reads ORM. This is a float branch and works with MaterialEditor without keywords.

Height / POM

ParameterType / range / defaultMeaning
HeightMapTexture
Default: Shader default		Height-v1 linear red channel, with its own tiling, offset, filter and wrap. White is the mesh envelope; black is HeightScale meters below it. Reverse is applied after data restoration. POM moves surface samples only, never coverage, shadow geometry, glass thickness or coat thickness. Use a matching normal map for lighting detail.
ParallaxModeFloat
Range: 0, 1
Default: 0		0 Off preserves the accepted pre-POM sampling. 1 POM traces the view ray through HeightMap, shifting material, normal/detail and coat/film maps together before each map's own ST. No plugin or saved keyword is required. UV-only: real depth, silhouette, light position and native shadows stay on the mesh.
HeightScaleFloat
Range: 0, 0.2
Default: 0		Maximum inward relief in world meters, corrected for UV density and nonuniform object scale. Zero bypasses height sampling and preserves pre-POM appearance regardless of the other height controls. White height remains at the mesh. This does not displace vertices or write pixel depth.
IsHeightReverseFloat
Range: 0, 1
Default: 0		Reverse decoded height with h=1-h before tracing. Normally white is high and black is recessed; reversed black is high. This does not invert alpha, coverage or any mask.
ParallaxQualityFloat
Range: 0, 1
Default: 0		0 Realtime: 12-32 angle-adaptive steps and 2 intersection refinements. 1 Reference: 32-96 steps and 5 refinements. Both preserve the same height/UV model and bounded gradients. Reference is a higher sampling budget, not an exact ray-traced ground truth. Each native ForwardAdd repeats the camera-ray search.
ParallaxFadeStartFloat
Range: 0, 100
Default: 15		Eye distance where relief starts smoothly fading to the mesh. Far/end and mip/grazing guards only affect relief; they do not fade coverage or material brightness.
ParallaxFadeEndFloat
Range: 0, 100
Default: 25		Eye distance where relief becomes flat. Values not above Fade Start are safely treated as a short positive interval. Very coarse height mips also fade relief automatically.
ParallaxGrazingFadeFloat
Range: 0.01, 0.5
Default: 0.15		View-normal cosine below which relief smoothly weakens. Limits instability at nearly tangent views; zero silhouette expansion and exact depth remain outside UV-only POM.
ParallaxMaxOffsetFloat
Range: 0.01, 2
Default: 0.25		Maximum full-ray excursion measured in HeightMap UV units after height tiling. Limits extreme offsets continuously by reducing effective relief, not by clipping the final UV. Texture wrap remains the HeightMap sampler's own setting. Atlas islands still require sufficient padding.
ParallaxSelfShadowFloat
Range: 0, 1
Default: 0		Optional local height-field visibility per native directional, point, spot and four-array fallback light. Default Off preserves the accepted POM appearance. Shadows the entire direct layered response once, not coverage, emission, SH, Probe or rectangle lights. No plugin or replacement shadow map is required.
ParallaxSelfShadowStrengthFloat
Range: 0, 1
Default: 1		Blend local height visibility into each native direct light. One applies the full estimated occlusion; zero bypasses the light-ray trace. Coat and thin film share one conformal relief surface and one visibility. Does not provide environmental occlusion or simulate a coat filling grooves.
ParallaxSelfShadowBiasFloat
Range: 0, 4
Default: 1		Dimensionless multiplier for the automatic effective-height and texture-footprint self-intersection bias. Larger values suppress acne but can leak light across fine relief. Quality follows ParallaxQuality: Realtime 8-16, Reference 24-48 light-ray steps. Grazing or excessive UV excursions fade to unshadowed local visibility; native shadows are retained.

Anisotropy

ParameterType / range / defaultMeaning
AnisotropyFloat
Range: 0, 1
Default: 0		OpenPBR-style GGX axis stretch; multiplied by AnisotropyMap red. 0 uses the original isotropic BRDF/LUT/probe path. 1 is numerically regularized per axis. Direct light uses anisotropic GGX/Smith and directional energy compensation; native Probe IBL uses an approximate bent reflection vector, not exact elliptical convolution.
AnisotropyRotationFloat
Range: 0, 360
Default: 0		Rotates the broad-slope tangent axis about the final shading normal in the UV frame; rotation-map red adds a full turn. 180 degrees is visually equivalent; 90 degrees swaps highlight axes. Mirrored UV and negative transforms preserve frame handedness.

Specular Filtering

ParameterType / range / defaultMeaning
SpecularAAStrengthFloat
Range: 0, 1
Default: 1		Filters GGX from final-normal derivatives. Anisotropy broadens both squared slope axes and filters direction variation; direct light, DFG and IBL share the effective parameters. 0 restores unfiltered parameters. Cannot recover subpixel variance lost by compression/mips.
SpecularAAVarianceFloat
Range: 0, 1
Default: 0.15		Weight of normal and anisotropic-direction derivatives. Larger values reduce tiny sharp highlights and isotropize rapidly varying directions. Neutral for a spatially constant normal and direction frame.
SpecularAAThresholdFloat
Range: 0, 1
Default: 0.2		Bounds the filtering kernel in microfacet-alpha space: added alpha-squared is at most threshold-squared times AA strength. 0 disables broadening.

Glints

ParameterType / range / defaultMeaning
GlintWeightFloat
Range: 0, 1
Default: 0		0 preserves the previous material. 1 replaces native direct-light substrate single scattering with footprint-filtered statistical glints. Coat, multiple scattering, diffuse, emission, SH, Probe and rectangles retain their existing response. No plugin or keyword required.
GlintDensityFloat
Range: 0, 8
Default: 6		Log10 statistical facets per original UV unit area: 6 means one million. Higher density or larger pixel footprints converge toward smooth GGX. Not world-meter density; UV islands with different texel density need authoring adjustment.
GlintContrastFloat
Range: 0, 1
Default: 0.5		Statistical sparsity: R=10^(-3*value). Higher values give fewer, brighter events at the same expected reflection, not an energy multiplier or another roughness. Extremely rare unresolved events continuously retain the smooth mean.
GlintSeedFloat
Range: 0, 65535
Default: 0		Rounded integer material seed, saved by ME. Changes the stable UV and angular statistical field. Time, frame number and light index never reseed it. Mirrored or repeated UV charts repeat the pattern.

CoatRoughnessFloat

Coat Absorption

ParameterType / range / defaultMeaning
CoatThicknessMapTexture
Default: Shader default		Red channel multiplies coat thickness in millimeters. This absorption distance is not nanometer thin-film thickness.
CoatAbsorptionColorColor
Default: Shader default		Linear single-pass transmission at CoatAbsorptionDistance. White means no absorption; not a tint added to reflections.
CoatAbsorptionDistanceFloat
Range: 0.001, 10
Default: 1		Distance in millimeters at which the transmission equals CoatAbsorptionColor.
CoatThicknessFloat
Range: 0, 2
Default: 0.05		Medium thickness in millimeters. Reflections traverse down and up; emission traverses only the escape path.

Thin Film

ParameterType / range / defaultMeaning
ThinFilmMaskTexture
Default: Shader default		Red channel multiplies ThinFilmWeight within the coat-covered region only.
ThinFilmThicknessMapTexture
Default: Shader default		Red channel multiplies ThinFilmThickness in nanometers. Data, not color; shared material-data sampler.
ThinFilmWeightFloat
Range: 0, 1
Default: 0		Optional interfering substrate interface beneath coat. Zero keeps plain coat; CoatWeight zero disables film too.
ThinFilmIORFloat
Range: 1, 3
Default: 1.4		Film refractive index, independent of coat and base IOR. RGB metal optical constants are an effective fit, not measured spectral data.
ThinFilmQualityFloat
Range: 0, 1
Default: 0		0: Realtime, using a shader-owned positive GGX energy projection table. Direct film interference is unchanged. High-contrast or thick low-index films smoothly return to the reference path. 1: Reference, the preserved 256-512 sample integral; much more expensive. Both modes are neutral when film or coat weight is zero.
ThinFilmThicknessFloat
Range: 0, 2000
Default: 400		Optical interference thickness in nanometers. Below 30 nm the film smoothly fades into the plain substrate; this is not a calibrated ultrathin oxide model. Spatial phase filtering reduces distant flicker.

Environment

ParameterType / range / defaultMeaning
OcclusionFloat
Range: 0, 1
Default: 1		Scalar ambient visibility; white mask or no map leaves this value unchanged. Also feeds the separately controlled specular-occlusion approximation.
OcclusionStrengthFloat
Range: 0, 1
Default: 1		Blends ambient visibility from 1 to Occlusion times its map. Does not change direct-light shadows.
IndirectDiffuseIntensityFloat
Range: 0, 4
Default: 1		Scales the blended Unity SH and Tom SH Volume diffuse illumination. Does not create bounced light when no environment data exists.
ReflectionIntensityFloat
Range: 0, 4
Default: 1		Scales decoded native reflection-probe radiance. Supports two probes, box projection and Unity sky fallback. Does not scale direct-light specular.
ProbeBoxProjectionFloat
Range: 0, 1
Default: 1		Enables each native probe's parallax box projection when the probe and Unity renderer provide it. Does not turn a sky cubemap into a local probe.
ProbeBlendingFloat
Range: 0, 1
Default: 1		Blends two native probes using Unity's receiver weights, in decoded linear radiance. Renderer must allow BlendProbes or BlendProbesAndSkybox. Off uses probe 0 only.
CustomSHVolumeBlendFloat
Range: 0, 1
Default: 1		Receives the existing Tom Lighting Probes SH volume MPB contract. Blends over native SH with per-pixel edge fading; falls back when missing, disabled or outside. Current runtime plugin targets CharaStudio.
SpecularOcclusionStrengthFloat
Range: 0, 1
Default: 1		Approximate view/roughness-aware visibility from ambient occlusion, for probe specular only. 0 preserves unoccluded reflections; white AO is neutral. Not ray-traced occlusion.
SpecularHorizonStrengthFloat
Range: 0, 1
Default: 1		Fades probe reflections directed below the geometric surface by a perturbed normal. Does not multiply direct lights or emission; 0 disables this fade.

Scene Lighting

ParameterType / range / defaultMeaning
SceneLightingFloat
Range: 0, 1
Default: 1		Accept the optional KKS companion v1 rectangle lights. Off, missing companion, or an incompatible protocol contributes exactly zero. Does not replace native lights, Probe or SH.
AreaLightIntensityFloat
Range: 0, 4
Default: 1		Multiplier for rectangle direct lighting only. Scene emitter colors are linear radiance; solid angle supplies geometric falloff. Prototype has no occlusion or area-light shadows.
AreaLightQualityFloat
Range: 0, 1
Default: 0		0: unchanged Realtime (LTC plus 16 residual samples for bare isotropic; 32 per MIS proposal for layered/anisotropic). 1: preserved 128-sample Reference. The optional companion synchronizes these ME floats to camera-scoped local variants; no saved keyword edits. Screenshot Reference can temporarily promote render/depth/video captures without changing this value or thin-film quality. Off/missing companion keeps native lights, probes and SH unchanged.

Input Contract

ParameterType / range / defaultMeaning
ColorTextureModeFloat
Range: 0, 2
Default: 0		0=KKS Linear sampling convention, 1=sampled RGB is explicitly sRGB encoded, 2=sampled RGB is already linear. Auto does not decode values a second time, even in a Gamma-built bundle. Controls MainTex and EmissionMask; alpha is never gamma decoded.
ColorValueModeFloat
Range: 0, 2
Default: 0		0=KKS Linear color-uniform convention, 1=explicit sRGB values, 2=explicit linear values. Applies to color controls, not numeric gains. Gamma authoring previews are not the KKS display pipeline.
DataTextureRestoreFloat
Range: 0, 1
Default: 0		0=preserve sampled scalar data; 1=undo unwanted sRGB decoding of data in the KKS Linear player, independent of the bundle build color space. Covers roughness, metallic, AO, ORM, anisotropy strength/rotation and AlphaMask red. Leave off for correctly imported data maps.
LightColorInputFloat
Range: 0, 1
Default: 0		0=treat Unity combined RGB/intensity as linear numeric light units, preserving intensity ratios. 1=decode the combined value as sRGB; this cannot separately recover light color and intensity in Gamma hosts.
ReflectionColorModeFloat
Range: 0, 2
Default: 0		After KKS Linear HDR decoding: 0=linear KKS radiance, 1=explicit sRGB radiance, 2=already linear radiance. RGBM exponent decoding is independent of the Gamma authoring project. No companion plugin is required for native probes.
CustomSHColorModeFloat
Range: 0, 2
Default: 0		0=KKS linear SH, 1=decode evaluated SH as sRGB, 2=linear SH. Use 1 only for a known legacy Gamma capture; post-evaluation decoding is approximate, not exact linear GI. Native Unity SH remains linear and works without the companion.
